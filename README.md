# Olist-E-Commerce-Data-Analysis
This repository contains the data cleaning, SQL transformation, and exploratory data analysis phases for the Olist Brazilian E-Commerce dataset.
📁 Project Structure:

    python_scripts/: Contains data preprocessing and cleaning scripts using Pandas & NumPy.

    sql_queries/: Contains SQL scripts for database querying and modeling.

    dashboard/: (Coming Soon) Power BI interactive dashboard
